v1.4 closure clarification: producing the worked reference closes the documentation treatment only. Production G3 cannot rely on an unaccepted operational or promised recovery prerequisite. G4 initial readiness must be available for the offered service before production activation; subsequent recurring G4 evidence remains a continuing obligation. Restricted test fixtures are not production activations.

This release supplies the linked documents and gap/decision registers. Documentation completion is checked by finding every claimed treatment at its linked location, verifying all reference IDs and document targets, and preserving baseline requirements and test status. It does not close a live implementation gap. The remaining work is stated in each gap’s closure-evidence field rather than hidden behind a generic “completed” label.

Gate numbers are stable identifiers, not permission to activate production before promised recovery and operating requirements are accepted.
