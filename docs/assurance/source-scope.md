# Available source scope and unrecovered documents

**Source-recovery disposition: original standalone RAD/TAD v1.2 documents are not
recovered.** This corrective release does not close that original-file completeness
claim. It searched the available Library for the named RAD/TAD family again and found
no original package. That is a retrieval boundary, not proof that no copy exists.

The current repository includes the available v1.4 reference, v1.1 delivery kits and
historical audits. [RAD](../architecture/RAD.md) and [TAD](../engineering/TAD.md) are
composition/reading views of those sources. They are valid repository navigation,
not imitations of the unavailable Word originals. The public-service solution,
transition and as-built standalone files are not claimed to be imported.

For this corrective code/doc release, maintain the available views and exact source
inventory. The architecture owner must separately decide whether the intended service
needs a new dedicated solution/transition/as-built document or must recover the original
package. New work must use new versioned identities, its own source basis and actual
approval status; no historical author, decision or source is reconstructed.

**Closure condition for missing-source scope:** supply the originals with digests and
an explicit import/disposition, or record the actual owner's acceptance of a newly
defined deliverable scope. No such approval is issued by this merge.
