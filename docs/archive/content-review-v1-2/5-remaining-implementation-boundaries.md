The reference architecture does not invent an installed environment. Before deployment, the responsible teams must complete the actual site topology, supported product/provider combination, precise handoff and routing details, resource placement, service objectives, identities/keys/protection endpoints, operation coverage and selected-control assessment. Main chapter 26 assigns each decision an owner and output.

The appropriate next technical deliverable is an implementation design for the selected first platform, derived from this reference architecture. A separate automation specification may define schemas, modules or orchestration internals when a concrete delivery system needs them; those details are not prerequisites to understanding this architecture.
