## Architecture Kit — Design, Decisions and Approval

*Build the decision baseline before selecting configuration values.*

Kit v1.0 • 16 September 2026 • Aligned to the frozen v1.4 reference architecture

Working kit, not an approved site design or deployed platform. Templates, reference examples and live evidence are separate records.

Use this guide with the HLD template and Architecture\_Registers.xlsx. The guide defines the work; the template captures the resulting design; the workbook tracks ownership, applicability and unresolved decisions.
