## Acceptance dependencies and the worked reference

The linked WD supplement connects the component inventory, isolated handoffs, exact illustrative routes, service permissions, provisioning receipts and verification assertions. It preserves the four-domain fixture while accounting separately for service-facing paths and temporary test resources. These are proposed reference values, not a site bill of materials. Production activation requires current G2 qualification, the applicable G4 operational and recovery readiness, per-workload checks and valid authority to operate. Restricted pre-production qualification can occur under a separate test authorization before G2 acceptance; it is not production Service Ready.

Authoritative linked treatment: [WD — Worked Infrastructure Design, Build Schedules and Acceptance](../../solutions/internal-protected-workload/README.md#V14_WD_START)
