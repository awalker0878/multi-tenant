# G04 — Site commissioning and inventory review

Review P04 against G04.01–G04.04 in the [gate specification](../../implementation/gates.md), using [P04 work packages](../../implementation/phases/p04.md). Inventory/platform owners and independent qualification/security observers evaluate bounded native read-only scope.

## Assemble the review

1. Pin commissioned endpoint/collector identities, installed tuples, scoped read privileges, profile contracts and source/artifact revisions.
2. Gather [Q02](../campaigns/q02-discovery-and-adoption.md) coverage, page/generation, identity, freshness, revocation, budget and ownership-safeguard reports.
3. Obtain independent authorized native snapshots and privilege boundaries for selected OpenStack/VMware labs. AHV contract completeness does not establish AHV native qualification.

## Criterion examination

| Criterion | Review action |
| --- | --- |
| G04.01 | Reconcile stable native IDs and provenance against the observer's scope; inspect every dimension of all three platform contracts for explicit fact or gap. |
| G04.02 | Examine partial/hidden pages, privilege gaps, reused IDs, stale generations and revoked collector behavior; confirm unapproved endpoints and guessed foreign IDs are denied. |
| G04.03 | Compare actual request rates/fairness to approved budgets; verify lost connection expires freshness and recovery reconciles a complete generation. |
| G04.04 | Inspect unowned observations and collision denials; compare before/after native state to prove discovery changed no resources or ownership. |

## Resolve the review

Reject completeness claims based only on record counts or successful API status. Scope/privilege limitations must remain visible to planning, and stale or partial generations cannot become eligible because the collector restarted.

Discovery satisfies observation obligations only. Do not accept import or name matching as native ownership transfer; P09 adoption has separate authority and Q02 cases.

Record exact lab tuples, scope limitations, evidence IDs, criterion findings, actual observer/reviewer/date and remedial packages. Update the [delivery register](../../implementation/delivery-register.yaml); no gate decision expands read scope or authorizes writes.

## Reopen when

Review affected findings after platform/API/privilege changes, identity normalization, collector enrollment/revocation, paging/generation/freshness or endpoint budget changes.
