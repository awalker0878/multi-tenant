## Implementation Kit — Commission, Qualify and Operate

*Run the accepted design; record the actual result.*

Kit v1.0 • 16 September 2026 • Aligned to the frozen v1.4 reference architecture

Working kit, not an approved site design or deployed platform. Templates, reference examples and live evidence are separate records.

Use this kit after a controlled engineering release. The runbooks identify actions and evidence, while the approved site method supplies exact native commands and configuration. No runbook in this kit is authority to change an environment.
