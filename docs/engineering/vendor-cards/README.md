## Vendor Realization and Shared-Infrastructure Cards

*A build track for each hosting stack and its shared foundations.*

Kit v1.0 • 16 September 2026 • Aligned to the frozen v1.4 reference architecture

Working kit, not an approved site design or deployed platform. Templates, reference examples and live evidence are separate records.

Use one card per selected realization. These cards state the native engineering decisions and build responsibilities; actual supported versions, settings, credentials and execution evidence must be entered in ET and the schedules.
