The primary design lineage is the v1.3 library included as frozen build input. References below identify protocol or product mechanism context. They do not identify installed versions or certify a platform. The release source-review register records which external pages were successfully retrieved during the build; retrieval alone is not a substantive compatibility review.

Related documents: [RA — Parent source register](../../architecture/reference/README.md#V14_RA_START)  \|  [VND — Vendor source and tuple limitations](../../engineering/platform-realizations/README.md#V14_VND_START)

## R14-01 — RFC 5737 — IPv4 Address Blocks Reserved for Documentation

Used only for the example address convention, not real allocations.

[Official source](https://www.rfc-editor.org/rfc/rfc5737)

## R14-02 — RFC 3849 — IPv6 Address Prefix Reserved for Documentation

2001:db8::/32 is the illustrative address convention.

[Official source](https://www.rfc-editor.org/rfc/rfc3849)

## R14-03 — RFC 2606 — Reserved Top Level DNS Names

The .example suffix denotes examples rather than operational name ownership.

[Official source](https://www.rfc-editor.org/rfc/rfc2606)

## R14-04 — RFC 7766 — DNS Transport over TCP: Implementation Requirements

General-purpose DNS TCP operation; the selected service still needs actual configuration and testing.

[Official source](https://www.rfc-editor.org/rfc/rfc7766)

## R14-05 — OpenStack Neutron — Networking concepts and security groups

Additive allow-policy and native defaults are mechanism context, not an installed-version support record.

[Official source](https://docs.openstack.org/neutron/latest/admin/intro-os-networking.html)

## R14-06 — RFC 7348 — Virtual eXtensible Local Area Network

Packet format informs the explicit illustrative MTU arithmetic; no universal Geneve or vendor overhead is claimed.

[Official source](https://www.rfc-editor.org/rfc/rfc7348)

All W14 and inherited infrastructure procedures are not-run. Local checks validate the example arithmetic and document structure only.
