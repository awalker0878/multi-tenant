# Architecture work

Begin with the [v1.4 reference architecture](../../reference/Portable_Hosting_Delivery_Kits_v1_1/05_Reference_v1_4/00_Reference_Architecture_v1_4.docx)
and [architecture kit](../../reference/Portable_Hosting_Delivery_Kits_v1_1/01_Architecture/Architecture_Kit.docx).
The [HLD and architecture review template](../../reference/Portable_Hosting_Delivery_Kits_v1_1/01_Architecture/HLD_and_Architecture_Review_Template.docx)
and [service design development](../../reference/Portable_Hosting_Delivery_Kits_v1_1/01_Architecture/Service_Design_and_Decision_Development.docx)
turn the reference into a scoped solution decision.

RAD, TAD and solution designs remain architectural document roles, not application
components. The archive being imported contains delivery kits v1.1 and architecture
v1.4. Separate RAD/TAD kit files described earlier were not present in this mounted
archive; no replacement has been fabricated or represented as imported. This library
links the actual HLD/LLD/service-design material available.

Record service envelope, trust/failure boundaries, co-residency, management,
sovereignty/location decisions, portability and provisioning ownership before
selecting implementation objects. [Artifact catalogue](../ARTIFACT_CATALOG.md).
